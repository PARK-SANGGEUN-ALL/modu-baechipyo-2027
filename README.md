# 모두의진학 | 2027 대입 배치표 (학생부종합 · 학생부교과)

> 진학의 정보를, 모두에게

전국 200개교의 **2026학년도 대학별 공개 입시결과**(대입정보포털 '어디가' 결과공개 자료)를 기반으로 만든
등급대별 배치표입니다. 설치·서버 없이 `index.html` 하나로 동작합니다.

## 배포 방법 (GitHub Desktop + GitHub Pages)
1. 새 저장소를 만들고 이 폴더의 파일을 그대로 복사합니다.
   - `index.html` (본체, 데이터 내장)
   - `thumbnail.png` (공유 썸네일 1200×630, 로고 포함)
   - `favicon.png`, `apple-touch-icon.png` (심벌 로고 아이콘)
   ※ 헤더 로고는 `index.html` 안에 base64로 내장되어 있어 별도 파일이 필요 없습니다.
2. GitHub Desktop에서 **Commit → Push**
3. 저장소 **Settings → Pages → Source: main / (root)** 로 설정
4. 몇 분 뒤 `https://<아이디>.github.io/<저장소명>/` 에서 열립니다.
   카카오톡·페이스북 등에 링크를 붙이면 `thumbnail.png`가 미리보기로 뜹니다.

## 데이터 기준
- 출처: 대입정보포털 '어디가' 2026학년도 대학별 입시결과 공개자료(대학 204곳 원본 엑셀)
- 대상: **수시 학생부위주(종합)·(교과)** 전형
- 지표: **최종등록자 학생부 환산등급 70%컷** (전 행이 동일 기준, 50%컷·평균 혼용 없음)
- 수록량: 학생부종합 6,233개 / 학생부교과 10,308개 모집단위 = 합계 16,541개
- 주간·야간 분리 모집은 모집단위명에 `(야간)` 표기
- 전형은 일반 / 지역인재 / 기회균형·사회통합 / 정원외로 분류해 필터 제공

## 5등급제 변환 보기
상단 **[5등급 변환]** 버튼을 누르면 9등급제 결과를 5등급제 값으로 환산해 배치표를 다시 그립니다.

- 환산 근거: **부산광역시교육청학력개발원 진로진학지원센터**
  「부산광역시교육청 관내 5등급제 고1 1~2학기 등급평균 분석 자료」(88개교 14,331명)
- 방식: 자료의 **누적비율**을 매개로 9등급 등급평균 → 5등급 등급평균을 선형보간
  (예: 9등급 3.35 = 상위 17.42% = 5등급 2.00)
- 각 칸에 5등급 변환값 · 상위 누적비율 · 원자료 9등급값을 함께 표시
- **참고용 추정치**입니다. 원 자료는 부산 지역 표본이고 대학 발표값은 9등급제이므로,
  지역·학교·과목 구성에 따라 달라질 수 있습니다.

## 인쇄 · PDF 저장 (A4)
표 위 **[🖨 인쇄 · PDF]** 버튼(또는 Ctrl/⌘ + P)을 누르면 A4에 맞춰 출력합니다.

- 인쇄용 레이아웃은 **한 모집단위 = 한 줄**로 압축되어 화면보다 훨씬 많은 내용이 들어갑니다
- 대학 3개교 이상 **가로 용지**, 1~2개교 **세로 용지** 자동 선택
- 표 크기를 재서 배율을 계산하되 **최소 60%까지만 축소**(그 이하로는 글자가 안 보이므로 축소하지 않고 여러 장으로 출력)
- 한 장에 안 들어가면 **등급을 0.5 단위로 자동으로 묶어** 다시 맞춥니다(머리글에 안내 표시). 화면에서도 **[등급 0.5 묶기]** 버튼으로 같은 방식으로 볼 수 있습니다
- 여러 장이 되면 각 장에 **대학명 머리행이 반복**됩니다
- 인쇄 글자 크기는 pt로 고정: 대학명 10.5pt, 등급 10pt, 모집단위 8pt, 컷 7.6pt
- 어두운 테마로 보고 있어도 **인쇄는 항상 밝은 색**, 등급 색 밴드는 유지
- 머리글 자동 생성: 제목 / 전형 / 등급 기준 / 필터 / 검색어 / 대학 목록 / 출력일 / 자료 출처

## 사용 팁
- 지역 버튼을 누르면 **그 지역 지도만** 크게 표시됩니다.
- 이름표가 지도 안에 들어가지 못하면 좌·우 여백에 정렬되고 보조선으로 연결됩니다.
- 오른쪽 위 **대학명 검색**으로 바로 추가, **모집단위 검색 + 전국에서 찾기**로 학과 기준 비교가 가능합니다.
- 표는 한 번에 최대 20개교까지 나란히 비교합니다.
